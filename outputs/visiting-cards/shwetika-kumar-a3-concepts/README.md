# Shwetika Kumar — Maitri A3 visiting card concepts

Three double-sided directions using Maitri's selected A3 Companion Circle Garland logo.

- `v1-warm-minimal-*`: quiet, warm, and versatile.
- `v2-plum-signature-*`: premium, confident, and memorable.
- `v3-story-world-split-*`: expressive and closest to the website's visual language.

## Production specifications

- SVG masters: 96 × 56 mm artboard.
- Intended trim: 90 × 50 mm.
- Bleed: 3 mm on every edge.
- Typography: Outfit, matching the Maitri website.
- Review PNGs: 1920 × 1122 px.
- A3 logo source: `outputs/logos/maitri-option-a-refinement/a3-companion-circle-garland.svg`.

## Placeholder content

The phone number, email address, and website use deliberately invalid placeholder values. Replace them with Shwetika Kumar's confirmed details before print production. A QR code has not been added because no confirmed destination URL was available.

## Export provenance

The card layouts and exact logo/text content are composed deterministically as SVG. PNG previews are raster review exports; the SVG files are the editable, resolution-independent masters. `render_review_board.py` generates the comparison image from those previews.
