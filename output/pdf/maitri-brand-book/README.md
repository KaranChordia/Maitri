# Maitri Brand Book 2026

This folder contains Maitri's working master brand book and the source used to generate it.

## Deliverables

- `Maitri_Brand_Book_2026.pdf` - 41-page landscape brand book
- `maitri_brand_book.py` - editable ReportLab source
- `assets/` - packaged website captures and approved motif PNGs used by the source

## Coverage

The book documents the brand foundation, audience, positioning, pillars, personality, voice, messaging, story principles, logo system, official palette, typography, motif vocabulary, imagery, UI, motion, website applications, companion storytelling, Manu, social/editorial use, packaging, and governance.

The supplied LEDGER brand book informed only the breadth and sequencing of the content. Maitri's design, visual language, copy, and examples were developed from the current Maitri strategy, website, character direction, logo, and approved icon assets.

## Regeneration

Run the source with a Python environment that includes ReportLab:

```sh
python maitri_brand_book.py
```
